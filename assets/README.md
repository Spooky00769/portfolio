# Portfolio assets

- Add the profile photo as `profile.jpg` in this folder.
- Add your real resume PDF as `resume.pdf` here, then set `resumeData.ready` to `true` in `../script.js`.
- Add future project thumbnails here and put their relative paths in `projectsData` in `../script.js` (for example, `assets/my-project.jpg`).

The portfolio shows designed placeholders until you add the real files.
